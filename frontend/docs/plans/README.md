### ⚠️ 이 확장에서 반드시 지킬 것

- **`ui-implementer` 를 병렬로 띄울 때** 각 태스크의 `Files` 목록 밖 파일을 건드리지 않게 프롬프트에 명시한다. `FE-1`·`FE-2` 산출물은 **모든 묶음이 읽기만** 한다.
- **자녀 본인 좌표는 지도에 올리지 않는다** — 학생 앱이 없어 좌표를 보내는 주체가 없다.
- **낙관적 UI 금지** — 서버 응답 뒤에만 상태를 옮긴다.
- **색만으로 상태를 구분하지 않는다** — 아이콘·문구를 함께 쓴다.
