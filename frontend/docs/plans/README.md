### 라우트 변화 — 9개 → 17개

| 역할 | 이전 | 이후 |
|---|---|---|
| 기사 | `/driver/route` `/driver/roster` | 동일 (**승하차 버튼 제거, 읽기 전용**) |
| **선탑자(신규)** | — | `/attendant/roster` `/attendant/route` |
| **학부모(신규)** | — | `/parent/home` `/parent/map` `/parent/request` |
| 관리자 | 4화면 | **5화면** — 관제 상세·배차 **확장** + `/admin/members` **신설** |
| 학생 | 없음 | **없음 유지** (범위 밖) |

> ⚠️ **`FE-1` 이 만드는 라우트는 5개가 아니라 6개다.** `FE-P4` 원본은 선탑자 2 + 학부모 3 만 적고 있어
> **`adminMembers` 와 관리자 셸 5번째 탭이 빠져 있다.** `FE-11` 은 그 둘을 전제로 하고 스스로 만들지 않는다
> (`app_routes.dart`·`app_router.dart` 는 병렬 안전선). **`FE-1` 착수 전에 `FE-P4` 를 먼저 보완한다.**

### ⚠️ 이 확장에서 반드시 지킬 것

- **`ui-implementer` 를 병렬로 띄울 때** 각 태스크의 `Files` 목록 밖 파일을 건드리지 않게 프롬프트에 명시한다. `FE-1`·`FE-2` 산출물은 **모든 묶음이 읽기만** 한다.
- **자녀 본인 좌표는 지도에 올리지 않는다** — 학생 앱이 없어 좌표를 보내는 주체가 없다.
- **낙관적 UI 금지** — 서버 응답 뒤에만 상태를 옮긴다. **삭제는 특히 그렇다**(409 로 거부될 수 있다).
- **색만으로 상태를 구분하지 않는다** — 아이콘·문구를 함께 쓴다.
- **`ApiClient.delete` 는 `FE-11` 만 만든다.** 지금 클라이언트에 HTTP DELETE 가 **없고**(실측) doc 주석이 *"`get`/`post`/`patch` 만 쓴다"* 고 계약을 명시하고 있다 — 코드와 주석을 **함께** 고친다.
- **`showDialog`·`AlertDialog` 선례가 저장소에 0건이다.** 파괴적 동작 확인은 다이얼로그가 아니라 **인라인 2단계**로 한다(`FE-P5c` §FE-11 Step 8).
