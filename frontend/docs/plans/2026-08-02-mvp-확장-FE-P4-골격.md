## 전역 제약

1. **Flutter + Riverpod.** 의존은 `presentation → application → data → core` 단방향, 역방향 import 금지(§1·§3). **`core/` 는 feature 를 모른다** — `lib/core/**` 가 `lib/features/**` 를 import 하면 위반(C-1).
2. **외부 패키지는 포트로 감싼다** — 교체 가능성 있는 기술만 `core/*/spec/` + `core/*/impl/`(§5). 화면이 `dio`·`stomp_dart_client`·`geolocator` 를 직접 import 하지 않는다.
3. **경로 문자열 리터럴 금지** — `AppRoutes` 상수로만(§8, C-4).
4. **색·간격은 테마 상수만** — `Color(0x…)`·`TextStyle(fontSize:)`·매직넘버 금지. `AppColors`·`AppSpacing`·`textTheme` 경유(C-8). **터치 48dp 이상**(`AppTouch.min`), 상태는 **색 + 아이콘 + 텍스트** 3중 표기.
5. 명령은 `frontend/` 에서 — `flutter analyze`(무경고) · `flutter test` · `dart format --set-exit-if-changed lib/`.

  ```dart
  // lib/core/ui/person_avatar.dart
  import 'package:flutter/material.dart';

  /// 원형 인물 아바타. 사진이 없거나 로드에 실패하면 **이름 이니셜**로 떨어진다.
  class PersonAvatar extends StatelessWidget {
    // size 기본 44 = 명단 한 줄 기준(DESIGN_SYSTEM §5.2)
    const PersonAvatar({super.key, required this.name, this.photoUrl,
        this.size = 44});

    final String name;
    final String? photoUrl;
    final double size;

    /// `substring(0, 1)` 이 아니라 `characters.first` — 결합 문자가 깨진다.
    String get _initial {
      final trimmed = name.trim();
      return trimmed.isEmpty ? '?' : trimmed.characters.first;
    }

    @override
    Widget build(BuildContext context) {
      final theme = Theme.of(context);
      final url = photoUrl?.trim();
      final fallback = Center(
        child: Text(_initial,
            style: theme.textTheme.titleMedium
                ?.copyWith(color: theme.colorScheme.onSurfaceVariant)),
      );
      return Container(
        width: size,
        height: size,
        clipBehavior: Clip.antiAlias,
        decoration: BoxDecoration(
          color: theme.colorScheme.surfaceContainerHigh,
          shape: BoxShape.circle,
        ),
        // errorBuilder: 깨진 이미지 아이콘을 내면 "데이터가 잘못됐다"로 읽힌다.
        // loadingBuilder: 로딩 중에도 이니셜을 유지한다 — 스피너를 넣으면
        // 목록 스크롤에서 아바타 자리가 계속 깜빡인다.
        child: url == null || url.isEmpty
            ? fallback
            : Image.network(url, fit: BoxFit.cover,
                errorBuilder: (context, error, stack) => fallback,
                loadingBuilder: (context, child, progress) =>
                    progress == null ? child : fallback),
      );
    }
  }
  ```

### 2. 소스·git 을 읽다 발견한 — 계획과 어긋나는 사실

1. **`isSupportedInMvp` 변경은 기존 테스트 2건을 반드시 깬다.** `jwt_decoder_test.dart` 의 `'MVP 지원 역할은 기사와 관리자뿐이다'` 가 `Role.parent` 를 `isFalse` 로 단언하고, `role_redirect_test.dart` 의 `'MVP 범위 밖 역할(학생·학부모)'` 그룹이 학부모를 포함해 반복한다. 지시서에는 "추가"만 있었으나 **기존 단언 수정이 함께 필요**해 FE-1 Step 8 로 넣었다.
2. **`quick_login_panel.dart:31-33` 주석이 D-A 와 정면 충돌한다.** *"선탑자 전용 계정은 없다 … `DRIVER` 로 흡수하기로 확정"* 이라며 **`MVP_RELEASE_TRACKER.md` §0 과 `PROJECT_MASTER_PLAN.md` §12.1 을 근거로 든다.** 그 두 문서도 같이 낡는데 `DOC-*` 범위(OVERVIEW §6)에 없다 — 팀 리드가 추가 여부를 판단해야 한다.
3. **선탑자 앱바 부제에 `DriverAppBarSubtitle` 을 재사용할 수 없다.** 그 위젯은 `GET /api/drive-sessions/bus/{busId}` 로 `serviceDate` 를 읽는데 **OVERVIEW §4.1 의 권한 확대 목록에 그 엔드포인트가 없다.** 선탑자가 열면 403 이다. 그래서 차 정보만 내는 `MyBusAppBarSubtitle` 을 따로 만든다 — 백엔드가 그 엔드포인트도 열어 주면 둘을 합칠 수 있다.
4. **알려진 결함 M3 이 실재하고, 생각보다 크다.** `AppRoutes.adminRouteDetail` 은 선언만 돼 있고 `app_router.dart:145` 는 `GoRoute(path: ':id')` 를 쓴다. 더 나쁜 건 그 상세 라우트의 `builder` 가 상세 화면이 아니라 **목록 화면(`AdminRouteListScreen`)을 그대로 다시 그린다**는 점이다(`app_router.dart:146`) — 노선 상세는 사실상 미구현이다. FE-1 Step 7 의 테스트는 `path: '/` 만 잡아 `':id'` 는 통과한다. **이 결함은 FE-1 범위 밖이라 고치지 않았다.**
5. **feature 간 의존 예외가 하나 더 늘어난 상태로 커밋된다.** 기존 위반(`rideevent/application/driver_roster_controller.dart` → `drivesession`)에 더해, FE-0 Step 4 로 커밋될 `driver_app_bar_subtitle.dart` 가 `bus` → `drivesession` 방향을 추가한다(파일 상단 주석이 스스로 인정한다). FE-4 이후 선탑자 화면이 같은 값을 필요로 하면 세 번째가 생긴다 — 그 시점에 `shared/domain/` 승격을 결정해야 한다. **새 코드가 이걸 선례로 삼지 않는다**(C-1).
